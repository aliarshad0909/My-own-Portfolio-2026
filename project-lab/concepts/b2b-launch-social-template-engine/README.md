# Brand-Locked Social Content & Carousel Template Kit — Representative Concept Workflow (`b2b-launch-social-template-engine`)

> **Honest Scope Disclosure (Concept):** This folder provides a lightweight, locally runnable representative workflow prototype for the **Brand-Locked Social Content & Carousel Template Kit** concept in the portfolio. It demonstrates the core validation and stage flow using synthetic data and is **not** a finished production application or client deployment.

## Problem Context

Founders post sporadically because every LinkedIn or Instagram graphic gets redesigned from scratch with mismatched typography.

## Prerequisites

- Node.js 20+ (zero external npm packages required).

## Setup, Run & Test

```bash
cd project-lab/concepts/b2b-launch-social-template-engine
cp .env.example .env   # optional placeholder config
node index.mjs
node --test test.mjs
```

## Teardown

No background services or databases are started; delete any local `.env` file if created.
