# Ali Arshad — Personal Studio

Monorepo for the portfolio website and its demonstration applications.

```
ali-arshad-personal-studio/
  ali-arshad-personal-studio/   Next.js portfolio (deployed to Vercel)
demos/
  commerce-storefront/          Project 01 — e-commerce storefront demo
docs/
  OPEN_SOURCE_RESEARCH.md       Licensing assessment for every foundation considered
```

- **Portfolio** — see `ali-arshad-personal-studio/ali-arshad-personal-studio/README.md` for setup, deployment and the pre-launch checklist, and `docs/CONTENT_GUIDE.md` in that directory for editing content.
- **Demos** — see `demos/README.md`. Each demo is deployed as its own Vercel project and is never merged into the portfolio's runtime.

## Honesty rules

These are enforced by the data model, not just by convention:

1. Every project states its **type** — Professional Work, Original Concept, or Open-Source Adaptation.
2. Every project states its **status** — Planned, In Development, Demo Ready, Verified or Published. Only `Published` is indexed by search engines.
3. Open-source adaptations carry an **attribution** block naming the upstream project, its licence and exactly what was changed. The project page refuses to look finished without one.
4. Planned work is listed as a pipeline, never as a finished project.
5. Demonstrations say they are demonstrations, in the interface itself.
6. No invented clients, testimonials, metrics or credentials anywhere.
