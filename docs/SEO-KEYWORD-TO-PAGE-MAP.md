## 3. Anti-Doorway, Truthfulness & AI-Search Governance Rules

1. **Zero thin/doorway location bloat:** Location pages without verified regional evidence remain `noindex` and excluded from `sitemap.xml` (verified automatically by `npm run seo:audit`).
2. **Zero visual-only index bloat:** All `529` visual-only catalog items (including the `435` jewelry visual reference sheets and `94` luggage/appliance visual plates) remain `200 OK` with downloadable branded PDFs and instant client-side catalog search, while carrying `robots: noindex, follow` so search engines prioritize the `907` spec-documented product pages and high-value service/blog/calculator hubs.
3. **Single canonical ownership:** Every flagship case study redirects permanently (`HTTP 308`) from `/work/[slug]` → `/case-studies/[slug]`, and `https://aliarshad.co` redirects permanently (`HTTP 308`) to `https://www.aliarshad.co`.
4. **Consistent public entity identity (`@id` + `sameAs`):** `Person`, `ProfessionalService`, `WebSite`, `llms.txt`, and article/service social bars all cite the exact same verified LinkedIn, Instagram, Facebook, and Upwork URLs with zero fabricated claims, ratings, or backlink promises.
